## Installation ohne Terminal
In GitHub `m659nhcsvw-del/Mathelernplatform` die vorhandenen Dateien `index.html` und `math_engine.py` durch die gleichnamigen Dateien aus diesem Paket ersetzen (über GitHub-Weboberfläche). `README.md` kann ebenfalls aktualisiert werden. GitHub Pages veröffentlicht danach automatisch die neue Version.

**Wichtig:** Die Fehlerdiagnose deckt bewusst nur ausgewählte typische Fehler ab; sie ist keine allgemeine Analyse aller denkbaren Lösungswege. Der Rechenkern akzeptiert x, Zahlen, Grundrechenarten und ganzzahlige Potenzen. Für den ersten Aufruf wird eine Internetverbindung benötigt.
